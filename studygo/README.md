# Study Go: product website
Standalone site (HTML, CSS, JS, no build step). Separate from the personal portfolio.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.
(An internet connection loads the Outfit font; a system font is used otherwise.)

## Edit
- Showcase screens: `js/screens.js` (list of images, titles, text). Images live in `assets/screens/`.
- Copy and sections: `index.html`. Colors and layout: `css/style.css` (variables at the top).

## Deploy
Upload the whole folder to Netlify (drag and drop), Vercel, GitHub Pages or Cloudflare Pages.

## Not included
A Figma prototype link (none supplied) and any store or download buttons (the app is not released).
